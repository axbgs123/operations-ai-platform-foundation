# 非开发者验收指南

这次测试的目标不是检查代码，而是判断一个没参与项目开发的普通人能否看懂并走完主要流程。建议测试者使用匿名编号，例如 `participant-01`；不记录真实姓名、手机号或邮箱。

## 开始前

主持人会给你一个测试地址和一次性邀请码，并准备好 AI 科技合成或明确授权的数据。不要输入真实平台密码、Cookie、验证码、商业秘密、个人隐私或真实客户资料。

项目当前使用 Mock 模型，输出可重复但不代表真实千问效果。扩展流程使用脱敏 Fixture，不进入真实创作者后台。风控只是辅助判断，不保证通过平台审核。

## 点击步骤

1. 打开公开 Demo，确认不需要邀请码。浏览示例后尝试修改一项内容，记录系统是否清楚说明只读。
2. 打开主持人提供的私有工作区入口，输入独立邀请码。
3. 创建或查看抖音和小红书两个测试账号，确认两个平台的指标没有混在一起。
4. 用主持人提供的合成表格导入内容。先看预览，再确认导入。
5. 按页面提示体验截图识别或扩展脱敏演示。检查上传目标服务器，预览、遮挡敏感区域，并在 Web 页面人工确认；不要进入真实平台页面。
6. 打开仪表盘和一条分析报告。用自己的话说明“状态—问题—原因—行动”，并点开引用核对数据。
7. 对分析选择 useful 或 not_useful，保存一条建议。
8. 打开事实资料，确认事实清单。遇到冲突时记录提示是否容易理解。
9. 生成下一条标题和文案，检查系统有没有加入未确认事实。
10. 查看封面模式说明；本次只观察合成/Mock 结果，不评价真实千问图片质量。
11. 导出一种便携格式，并确认下载内容不包含邀请码或密钥。
12. 主动退出或解绑，记录是否容易找到操作。

全过程按真实时间填写模板。遇到问题不要猜，也不要让主持人直接替你完成；先记录问题和严重度，再注明是否需要帮助。测试结束后把匿名、脱敏记录交给主持人复核。
