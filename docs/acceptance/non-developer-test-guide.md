# Task 9B 独立非开发者验收指南

当前状态：`not_run`
原因：`independent_non_developer_session_pending`

本指南只用于准备下一次真实测试，不代表测试已经发生。参与者必须没有参与项目开发，并使用匿名编号（例如 `participant-01`）；不得记录姓名、手机号或邮箱。

## 测试边界

- 只使用人工合成或明确授权的 AI 科技内容。
- 不输入真实平台密码、Cookie、验证码、模型密钥、商业秘密或真实客户资料。
- 当前普通流程使用 Mock Provider（Mock 模型）；不代表真实千问效果。
- 不进入真实创作者后台；真实抖音/小红书页面兼容性仍为 `not_run`。
- 风控结论是辅助判断，不保证通过平台审核。

## 主持人开始前准备

1. 启动隔离临时测试环境，确认不连接原持久化数据库或原 Docker 卷。
2. 创建全新合成工作区、抖音合成账号和 Editor 独立邀请码。
3. 准备合成 Excel、截图、事实资料和风格参考；文件不得含真实账号或私有正文。
4. 打印或单独发送[参与者任务卡](./non-developer-participant-task-card.md)。
5. 打开空白[测试记录模板](./test-session-template.md)，不要预填结果。

## 参与者独立任务

参与者按任务卡独立完成以下 11 项：

1. 使用 Editor 邀请码进入私有工作区。
2. 判断当前工作区、平台和账号。
3. 找到工作台主要模块。
4. 导入合成 Excel。
5. 在暂存预览中检查并确认导入数据。
6. 查看一条内容详情和分析。
7. 找到爆款素材库、账号风格和事实资料。
8. 使用 Mock Provider 完成一次五步生成。
9. 查看发布前检查并识别固定免责声明。
10. 返回原队列，确认 platform、account、筛选、排序和分页未丢失。
11. 找到导出与备份入口。

## 主持人允许与禁止的行为

主持人只能：

- 提供 Editor 邀请码和合成测试材料；
- 宣布开始并记录真实时间；
- 逐字或脱敏摘要记录参与者主动提出的卡点、求助和评价；
- 在参与者明确求助后记录求助发生，但不能把被帮助步骤算作独立完成。

主持人不得：

- 代替参与者点击、输入、选择或解释下一步位置；
- 暗示导航标签或正确答案；
- 用开发者工具、内部 API 或预置 URL 跳过参与者路径；
- 补写不存在的时间、评价、成功率或卡点；
- 把主持人操作记成参与者完成。

## 结束与记录

记录真实开始/结束时间、每步结果、求助次数、阻塞严重度和参与者原话摘要。若某步未完成，明确写 `未完成`；若会话未发生，模板保持：

```text
status: not_run
reason: independent_non_developer_session_pending
```

测试结束后删除临时邀请码、临时对象、临时容器、网络和卷；保留的证据只包含匿名、脱敏记录。
