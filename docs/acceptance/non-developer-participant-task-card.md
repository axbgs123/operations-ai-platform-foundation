## 任务

1. 使用主持人提供的 Editor 邀请码进入私有工作区。

3. 找到工作台的主要模块，并说明你认为数据导入、分析、生成和导出分别在哪里。
4. 使用合成 Excel 发起一次导入。
5. 查看暂存预览，检查字段后确认数据入库。
6. 打开一条内容详情，再找到它的分析结果。
7. 分别找到爆款素材库、账号风格和事实资料。
8. 使用 Mock Provider 完成“范围与目标 → 事实资料 → 风格与参考 → 生成与编辑 → 复核与保存”五步流程。
9. 找到发布前检查，并读出页面对风控结果的限制说明。
10. 返回你进入内容详情前的原队列，确认平台、账号、筛选、排序和页码是否还在。
11. 找到导出与备份入口。
