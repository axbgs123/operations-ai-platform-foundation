# 通用模型与运营智能体聊天自动化验收证据

验证日期：2026-08-12。环境为 macOS、隔离 PostgreSQL/Redis、Chromium 和 Mock/Fake
Provider。没有使用真实 API Key、运营数据或计费模型，也没有修改原持久化数据库。

## 已通过

- Admin 可保存自带 OpenAI 兼容文本配置；读取时不返回密钥、密文或完整端点。
- 服务地址的协议、凭据、路径、DNS、私网/回环和重定向边界有自动测试。
- 连接测试只访问 `/models`，能区分鉴权、模型缺失、响应不兼容和安全阻断。
- 结构化文本调用复用工作区配置、严格输出验证、用量治理和安全错误合同。
- 聊天会话与消息按工作区和成员隔离，支持幂等、分页、归档和 4,000 字限制。
- 用户消息在外部模型调用前独立提交，模型失败时消息仍保留。
- “对话”刷新后恢复历史；“任务与执行”继续完成原九步计划批准和执行闭环。
- 并发请求生成相同每日简报时复用胜出记录，不再触发唯一键页面错误。
