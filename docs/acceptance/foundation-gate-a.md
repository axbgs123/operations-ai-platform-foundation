# Foundation Gate A 验收清单

## 自动门禁

- OpenAPI 文档与 TypeScript 生成类型无漂移。
- Web lint、类型检查和组件测试通过。
- API 单元/集成/架构测试通过，DeprecationWarning 视为错误。
- Alembic 已升级到 head，`alembic check` 不产生新迁移。
- Compose 配置、API/Web 镜像构建与敏感信息扫描通过。
- Playwright 冒烟覆盖公开 Demo、双平台账号和作品详情。

## 人工快速验收

1. 打开 `/demo`，确认抖音和小红书示例账号均标注“示例数据”，生成结果标注 Mock。
2. 创建工作区，用管理员邀请码进入；分别生成编辑者、查看者邀请码。
3. 创建抖音和小红书账号，修改账号目标、指标优先级和默认 30 条动态基准。
4. 新建作品，修改草稿，上传封面/截图/参考图/文档，刷新后确认素材仍可下载。
5. 发布作品后确认标题、正文和配置版本形成快照；归档、软删除与恢复符合预期。
6. 用其他工作区和查看者身份尝试写入，确认分别得到 404 和 403。

人工验收只使用本地或测试数据，不上传真实账号凭证和商业素材。
