# 扩展整页采集、快捷键与长期设备连接设计

日期：2026-08-10
状态：待用户书面规格确认

## 1. 目标

把现有“打开扩展 → 拖选区域 → 预览 → 上传”流程改造成面向运营人员的低操作成本流程：

- 在支持页面按快捷键或点击按钮即可开始采集；
- 默认自动从页面顶部滚动到底部，拼接当前页面已加载及滚动过程中加载的内容；
- 不再要求用户先拖选截图区域；
- 遮挡敏感信息为可选功能，默认关闭；
- 连接体验长期有效，除非用户解绑、管理员撤销或成员失效；
- 继续保留上传前预览和最终确认，不允许无感截图或自动上传。

## 2. 明确不做

- 不增加 `<all_urls>`、`cookies`、`tabs`、`webRequest` 或 `debugger` 权限。
- 不绕过平台登录，不读取 Cookie、密码、邀请码或浏览器历史。
- 不自动发布内容，不替用户确认正式数据。
- 不承诺无限滚动页面一定完整；采集受 30 屏、20 秒、像素及文件大小上限约束。
- 不把一个永久有效的明文 Bearer Token 写入本地存储。
- 不把遮挡默认开启，也不在用户未确认前上传截图。

## 3. 用户入口

### 3.1 默认快捷键

- macOS：`Command + Shift + 8`
- Windows / Linux：`Ctrl + Shift + 8`
- 快捷键只在 Chrome 获得焦点时工作，不声明全局快捷键。
- 使用 Manifest V3 `commands` 声明标准命令 `capture-full-page`。
- Service Worker 通过 `chrome.commands.onCommand` 接收命令。Chrome 官方文档确认 Commands API 可定义平台快捷键；命令触发也属于可授予 `activeTab` 的用户手势。
- 快捷键冲突时，扩展通过 `chrome.commands.getAll()` 显示“快捷键未分配”，并告诉用户前往 Chrome 的扩展快捷键设置修改。

快捷键信息必须出现在：

1. 扩展未连接/已连接两种 Popup；
2. 工作台“连接扩展”弹窗；
3. 安装说明和验收材料；
4. 首次连接成功提示。

### 3.2 点击入口

- Popup 主按钮改为“自动采集整页”。
- “截取当前可见区域”和现有“拖选局部区域”保留在“更多采集方式”中，作为失败降级和特殊场景备用入口。
- 快捷键与主按钮进入同一个采集协调器，不维护两套业务规则。

## 4. 整页滚动采集流程

### 4.1 状态机

`idle → validating → preparing → scrolling_capture → stitching → preview_ready → uploading → processing → review_ready`

任一阶段发生标签页切换、URL/平台/页面签名变化、页面隐藏、窗口失焦、账号变化、截图尺寸异常或用户取消，立即进入 `cancelled` 或 `failed_safe`，清除内存中的切片和拼接图。

### 4.2 启动前检查

Service Worker 必须再次确认：

- 命令或按钮来自明确用户手势；
- 当前活动标签页属于声明的抖音或小红书创作者页面；
- URL、平台、页面版本和页面签名与 Content Script 报告一致；
- 设备连接未撤销，短期访问令牌有效或已安全续期；
- 同一标签页当前没有另一条采集任务。

### 4.3 自动滚动和停止规则

Content Script 在 `try/finally` 中记录原始滚动位置，并执行：

1. 滚动到页面顶部；
2. 等待布局稳定；
3. 请求 Service Worker 对当前可见区域执行一次 `captureVisibleTab`；
4. 按约 85% 视口高度向下滚动，保留重叠区用于拼接校验；
5. 等待懒加载和布局稳定，再采集下一屏；
6. 连续两次检测到页面高度不再变化且已到达底部时结束；
7. 最多采集 30 屏或运行 20 秒，先达到者结束；
8. 在 `finally` 中恢复原始滚动位置和扩展临时 UI 状态。

Chrome 官方文档规定 `captureVisibleTab` 最多调用 2 次/秒，因此协调器必须限制调用频率，不得并发截图。

### 4.4 拼接和文件限制

- 每张切片记录截图尺寸、CSS 视口、DPR、滚动位置、页面高度和时间。
- 每次截图前后重新校验视口与 DPR；变化即停止，不猜测缩放比例。
- 使用滚动位置和重叠区校验拼接，裁掉已确认的重叠像素。
- 对固定/粘性导航仅做保守的重复区域识别；无法可靠去重时保留原图并在预览中提示，不能删除不确定的业务内容。
- 拼接结果最多 40,000,000 像素、最长边 32,000 像素、编码后 10 MiB。
- 达到资源上限时保留已成功采集的部分，并显示“页面内容过长，已截取前 N 屏”，不得伪称完整。
- 不支持使用 `debugger`/DevTools 协议换取整页截图。

### 4.5 降级

- 页面无法安全滚动、截图尺寸不一致、Canvas/内存不足或拼接失败：回到 `failed_safe`，允许用户选择“截取当前可见区域”。
- 超时或无限加载：保留已确认的部分结果进入预览，并明确标记“部分页面”。
- 失败时不自动上传，也不自动切换为其他采集范围。

## 5. 预览与可选遮挡

- 自动截图结束后必须进入完整预览，默认显示“遮挡敏感信息：关”。
- 遮挡关闭时不显示绘制工具，最终上传的 `redactions` 为空数组。
- 用户主动打开后，才显示“添加遮挡、删除遮挡、全部清除”等工具；遮挡继续使用不透明矩形，并在最终图片中烧录。
- 切换为关闭时必须询问是否清除已画遮挡；确认清除后才关闭，避免用户误以为遮挡仍生效。
- 无论遮挡是否开启，都必须由用户点击“确认上传”。
- 预览显示：采集屏数、是否完整、图片尺寸、文件大小、平台和账号范围、Mock/真实识别说明。

## 6. 长期设备连接

### 6.1 用户语义

“永久连接”定义为：同一浏览器配置文件和同一扩展安装中，连接一直保留，直到发生以下任一事件：

- 用户主动解绑；
- 管理员撤销该设备；
- 成员被移除或权限降级到不允许采集；
- 工作区被删除；
- 浏览器数据、扩展或设备密钥被清除；
- 服务端检测到设备凭证异常并撤销。

一次性配对码仍保持 5 分钟，避免泄露后长期可兑换；延长的是配对后的设备连接体验。

### 6.2 设备密钥方案

- 首次配对前，Service Worker 使用 WebCrypto 生成设备级非导出签名密钥。
- 私钥以不可导出的 `CryptoKey` 保存到扩展自己的 IndexedDB；不得写入普通字符串 storage、日志、备份或页面上下文。
- 服务端仅保存设备公钥、指纹、工作区、成员、客户端版本、创建/最后使用/撤销时间和状态。
- 初次配对请求同时提交公钥；服务端返回现有短期访问令牌和设备绑定 ID。
- 浏览器重启或访问令牌接近过期时：服务端签发一次性 challenge，Service Worker 使用设备私钥签名，服务端验证后签发新的短期访问令牌。
- challenge 短期有效、单次使用、绑定设备/工作区/client，并有幂等与限流。
- 设备密钥不可用、签名失败或服务端状态不一致时，明确要求重新连接；不降级到永久 Bearer Token。

### 6.3 令牌和撤销

- 短期访问令牌继续只保存在 `chrome.storage.session`，默认有效 8 小时。
- 续期在剩余 30 分钟以内、用户触发采集或 Popup 打开时按需执行，不使用无边界定时轮询。
- 撤销设备后，续期立即拒绝；现有访问令牌通过服务端设备状态检查立即失效，而不是等待 8 小时自然过期。
- 工作台成员与扩展管理页增加“已连接设备”列表：设备名称、浏览器、首次连接、最近使用、状态和“撤销”操作；不显示公钥正文、令牌或设备秘密。

## 7. 数据与 API 变化

新增或扩展：

- 设备绑定模型：`extension_device_bindings`；
- 一次性 challenge 模型：`extension_device_challenges`，或使用具备原子消费语义的短期 Redis 记录；
- `POST /v1/extension/pair`：接收设备公钥和客户端版本；
- `POST /v1/extension/session/challenge`：创建绑定设备的一次性 challenge；
- `POST /v1/extension/session/renew`：验证签名并返回新短期访问令牌；
- `GET /v1/workspaces/{workspace_id}/extension-devices`：Admin 查看设备；
- `DELETE /v1/workspaces/{workspace_id}/extension-devices/{device_id}`：Admin 撤销设备。

工作区隔离、跨工作区 404、Viewer 只读、Editor 不管理设备的规则保持不变。数据库迁移必须新增文件，不修改历史迁移。

## 8. 组件边界

- `CommandController`：解析快捷键，只负责触发统一采集入口。
- `CaptureCoordinator`：状态机、取消 fencing、页面再校验和模式选择。
- `ScrollCaptureDriver`：滚动、稳定检测、切片元数据和恢复位置。
- `Stitcher`：重叠校验、裁剪、拼接、资源上限和部分结果标记。
- `PreviewController`：预览、遮挡开关、确认上传，不负责截图。
- `DeviceKeyStore`：生成/读取非导出设备密钥，不处理网络。
- `SessionRenewalClient`：challenge/签名/续期，不读取页面正文。
- `ExtensionDeviceService`：服务端设备注册、验证、撤销和审计。

这些组件通过严格类型消息通信，Content Script 永远不能直接读取 `chrome.storage.session`。

## 9. 错误与文案

面向运营人员使用简明文案：

- 快捷键冲突：`快捷键未生效，请在 Chrome 扩展快捷键设置中重新指定。`
- 页面过长：`页面仍在加载，已截取前 18 屏。请预览后再上传。`
- 页面变化：`页面内容发生变化，本次采集已停止，请重新开始。`
- 连接续期失败：`设备连接已失效，请重新连接工作区。`
- 拼接失败：`无法安全拼接整页，你可以改为截取当前可见区域。`

不得向用户承诺“百分百截取全部内容”或“自动通过平台审核”。

## 10. 测试与验收

### 10.1 自动化

- Manifest 快捷键、平台键位和无新增敏感权限；
- 命令触发与 Popup 按钮进入相同协调器；
- 非支持页、非活动标签页、URL/平台/签名漂移全部拒绝；
- 30 屏、20 秒、两次高度稳定、2 次/秒速率限制；
- 懒加载、高度变化、固定导航、DPR/视口变化、截图尺寸不匹配；
- 拼接重叠、部分结果、像素/边长/10 MiB 上限；
- 原滚动位置在成功、取消、失败和异常中均恢复；
- 遮挡默认关闭，开启/清除/烧录及确认上传门禁；
- 设备密钥不可导出、浏览器重启续期、challenge 重放拒绝、撤销立即失效；
- 工作区/成员/平台/设备隔离和 Admin 权限；
- Chrome/Edge 构建、经典 Content Script、自包含产物、确定性 ZIP 和秘密扫描。

### 10.2 真实 macOS Chrome

- 重新加载扩展后核对版本、快捷键和权限；
- 使用合成工作区验证 Popup 长期连接和浏览器重启后自动续期；
- 在脱敏合成长页面验证快捷键、自动滚动、30屏/20秒停止、恢复滚动位置；
- 验证遮挡默认关闭、手动开启和最终确认；
- 验证当前可见区域与局部拖选降级入口；
- 不在真实抖音/小红书账号页面执行，真实平台兼容性继续标为 `not_run`。

## 11. 官方约束依据

- Chrome Commands API：<https://developer.chrome.com/docs/extensions/reference/api/commands>
- Chrome activeTab：<https://developer.chrome.com/docs/extensions/develop/concepts/activeTab>
- Chrome tabs.captureVisibleTab：<https://developer.chrome.com/docs/extensions/reference/api/tabs>

官方约束确认：快捷键属于 `activeTab` 的明确用户手势；`captureVisibleTab` 需要 `activeTab` 或更宽 host 权限；本设计继续使用最小 `activeTab`，不引入 `<all_urls>`。
