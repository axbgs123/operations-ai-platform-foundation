# 运营工作台双层导航改版规格

日期：2026-08-01

状态：用户已批准方案 B

产品基线：

- `docs/superpowers/specs/2026-07-20-operations-ai-platform-design.md`
- `docs/superpowers/specs/2026-07-29-workbench-frontend-redesign-design.md`

## 1. 背景

新版工作台已经为16个正式模块提供统一左侧导航，但当前侧栏同时展开全部小类。虽然界面存在“内容运营、策略资产、AI创作”等分组标题，用户首先看到的仍是一列数量较多、层级相近的功能入口，需要逐项阅读才能判断应该进入哪里。

真实使用反馈是：

> 左侧分类太细，应该先分一个大类，再细分小类。

本次改版只调整导航信息架构与交互，不删除功能、不改变规范路由、不修改角色权限、不调整页面业务内容。

## 2. 目标

1. 用户第一眼只需要理解5个稳定大类。
2. 选择大类后，只显示该大类下与当前角色相关的小类。
3. 当前大类、当前页面和工作区层级始终明确。
4. 16个正式模块不再同时争抢注意力。
5. 高频页面保持最多两次明确点击到达。
6. 深链接、刷新、前进、后退可以恢复正确的大类和小类。
7. 桌面端保持专业工作台效率，手机端使用适合窄屏的两步抽屉。
8. 导航改版后重新执行独立非开发者测试。

## 3. 非目标

1. 不新增分类首页。
2. 不增加第三层可点击导航。
3. 不修改现有页面路由。
4. 不修改Admin、Editor、Viewer权限。
5. 不修改Scope、`returnTo`或工作区隔离规则。
6. 不修改顶部栏、页面内容、API或数据库。
7. 不引入第三方组件库、图标库或在线字体。
8. 不使用大类折叠隐藏当前层级。

## 4. 已批准方案

采用“双层工作台导航”：

1. 一级大类栏固定显示5个大类。
2. 二级小类栏只显示当前大类下的功能。
3. 页面内容位于二级栏右侧。
4. 桌面端可以单独收起二级栏，一级大类栏始终保留。
5. 手机端使用“大类列表 → 小类列表”的两步抽屉，不并排显示两栏。

不采用：

- 单栏手风琴：菜单展开和收起会导致入口位置持续移动。
- 大类入口页：高频功能会多一次点击，小类入口也不能常驻。

## 5. 分类结构

### 5.1 总览

| 小类 | 规范路由 | 首次进入默认 |
| --- | --- | --- |
| 工作台总览 | `/workspaces/{workspace_id}` | 是 |

### 5.2 运营

按日常任务频率排序：

| 小类 | 规范路由 | 首次进入默认 |
| --- | --- | --- |
| 内容库 | `/workspaces/{workspace_id}/contents` | 是 |
| 数据导入 | `/workspaces/{workspace_id}/imports` | 否 |
| 分析中心 | `/workspaces/{workspace_id}/analysis` | 否 |
| 账号仪表盘 | `/workspaces/{workspace_id}/accounts` | 否 |
| 栏目与活动 | `/workspaces/{workspace_id}/columns` | 否 |

### 5.3 创作

| 小类 | 规范路由 | 首次进入默认 |
| --- | --- | --- |
| 生成中心 | `/workspaces/{workspace_id}/generation` | 是 |
| 发布前检查 | `/workspaces/{workspace_id}/preflight` | 否 |

### 5.4 资产

| 小类 | 规范路由 | 首次进入默认 |
| --- | --- | --- |
| 爆款素材库 | `/workspaces/{workspace_id}/viral-library` | 是 |
| 账号风格 | `/workspaces/{workspace_id}/styles` | 否 |
| 事实资料 | `/workspaces/{workspace_id}/facts` | 否 |

### 5.5 管理

按通用操作在前、管理员治理在后排序：

| 小类 | 规范路由 | 首次进入默认 |
| --- | --- | --- |
| 导出与备份 | `/workspaces/{workspace_id}/data-management/exports` | 是 |
| 后台任务 | `/workspaces/{workspace_id}/settings/jobs` | 否 |
| 风控知识库 | `/workspaces/{workspace_id}/risk-knowledge` | 否 |
| 回收站 | `/workspaces/{workspace_id}/data-management/trash` | 否 |
| 工作区设置 | `/workspaces/{workspace_id}/settings` | 否 |

“通用操作”和“管理员治理”可以在二级栏中使用不可点击的辅助分隔文字，但不得形成第三层导航。

## 6. 角色可见性

导航继续使用现有服务端角色结果和前端展示矩阵。

### 6.1 Admin

- 显示5个大类。
- 显示全部16个正式模块。

### 6.2 Editor

- 显示5个大类。
- 显示现有13个允许模块。
- 管理大类仅显示“导出与备份”和“后台任务”。
- 不显示风控知识库、回收站和工作区设置。

### 6.3 Viewer

- 显示总览、运营、创作、资产4个大类。
- 显示现有9个只读模块。
- 不显示管理大类，因为该角色在管理大类下没有可见小类。

### 6.4 Demo

- 不使用私有工作区双层导航。
- 保持公开Demo与私有WorkspaceShell隔离。

规则：

1. 如果某角色在一个大类下没有任何可见小类，整个大类不显示。
2. 前端隐藏只影响可发现性，不能代替服务端鉴权。
3. 角色变化后，已经不可访问的历史导航偏好必须被忽略。

## 7. 桌面布局

### 7.1 尺寸

- 一级大类栏：80px。
- 二级小类栏：184px。
- 完整导航总宽度：264px。
- 二级栏收起后：仅保留80px一级栏。
- 顶部栏和主内容布局继续使用现有WorkspaceShell。

相较当前240px侧栏，完整状态只增加24px，不应明显压缩仪表盘和表格。需要宽内容时，用户可以收起二级栏。

### 7.2 一级大类栏

每个大类同时显示：

- 明确图标。
- 两至四字中文标签。
- 选中状态。
- 可访问名称。
- 键盘焦点样式。

顺序固定为：

> 总览 → 运营 → 创作 → 资产 → 管理

一级栏不显示功能计数和运营指标，避免变成第二个仪表盘。存在需要注意的任务时，继续由顶部栏安全提示，不在一级栏使用动态数字造成注意力竞争。

### 7.3 二级小类栏

二级栏包含：

- 当前大类名称。
- 当前大类的小类列表。
- 当前页面高亮。
- 收起二级栏按钮。

二级栏不重复显示其他大类，不使用手风琴，也不显示没有权限的入口。

### 7.4 收起行为

1. 只收起二级小类栏。
2. 一级大类栏始终保留。
3. 收起后，通过一级大类高亮、图标Tooltip和顶部面包屑表达当前层级。
4. 当前页面不因为收起导航而改变。
5. 偏好按成员保存为`expanded`或`collapsed`，不保存业务数据或秘密。
6. 原有侧栏偏好可以直接迁移：`expanded`表示双栏，`collapsed`表示只显示一级栏。

## 8. 导航行为

### 8.1 当前状态来源

当前大类和小类必须由规范URL推导，不能只依赖组件本地状态。因此：

- 深链接可以正确高亮。
- 刷新后层级不丢失。
- 前进、后退可以恢复。
- 旧兼容路由重定向后可以落到正确分类。

### 8.2 点击大类

点击大类后：

1. 如果用户当前已经位于该大类，保持当前页面。
2. 如果从其他大类进入，优先跳转到该成员最近访问且仍有权限的小类。
3. 没有合法历史记录时，跳转到该大类的首次进入默认页面。
4. 历史记录只保存规范相对路由，不保存查询中的业务正文、邀请码、Token或外部地址。
5. 历史记录必须重新通过角色、工作区和大类归属校验。

各大类默认页：

- 总览：工作台总览。
- 运营：内容库。
- 创作：生成中心。
- 资产：爆款素材库。
- 管理：导出与备份。

### 8.3 点击小类

- 使用现有规范路由。
- 在目标页面支持相同Scope时保留合法`platform`和`account`。
- 不支持时按照现有规则清除并说明。
- `returnTo`继续使用现有工作区内部安全校验。

## 9. 面包屑

私有工作区页面统一显示：

> 工作区 / 大类 / 当前页面

内容、账号或其他资源详情可以继续追加资源层级，例如：

> 工作区 / 运营 / 内容库 / 内容标题

面包屑中的大类链接与一级大类行为一致。不得通过面包屑产生外部跳转或绕过权限。

## 10. 手机端

小于768px时继续使用单个模态抽屉，但内部变为两步结构。

### 10.1 第一步：大类

- 显示当前角色可见的大类。
- 显示图标和完整中文标签。
- 不在第一屏同时展开全部小类。

### 10.2 第二步：小类

- 顶部显示当前大类。
- 提供“返回全部分类”。
- 只显示当前大类允许的小类。
- 选择小类后关闭抽屉并导航。

### 10.3 深链接

在深链接页面打开抽屉时，默认进入当前大类的小类列表；用户可以返回全部分类。

继续满足：

- `dialog`和`aria-modal`语义。
- 焦点锁定。
- Escape关闭。
- 关闭后焦点返回触发按钮。
- 抽屉打开时背景不可交互。
- 导航后自动关闭。
- 不依赖悬停。

## 11. 可访问性

1. 一级大类使用可导航链接，不能只用不可访问图标按钮。
2. 一级和二级分别提供明确的`aria-label`。
3. 当前大类和当前小类使用`aria-current`或等价语义。
4. 收起后的一级大类仍显示中文短标签；Tooltip不能成为唯一名称。
5. 图标标记为装饰性，名称来自可见文字。
6. 所有状态同时使用颜色、背景和文字/语义。
7. 键盘Tab顺序为：跳转主内容 → 一级大类 → 二级小类 → 顶部栏 → 主内容。
8. 动画遵守`prefers-reduced-motion`。

## 12. 状态与降级

### 12.1 工作区上下文加载中

- 使用与双层导航尺寸一致的Skeleton。
- 不短暂渲染Admin全部入口。

### 12.2 上下文加载失败

- 显示安全错误状态和重新加载。
- 不显示可能无权限的历史菜单。

### 12.3 会话失效或成员撤销

- 清除当前成员的展示偏好和最近访问记录。
- 返回安全入口。
- 不保留私有页面内容。

### 12.4 未知路由

- 不根据字符串模糊猜测大类。
- 使用安全的未匹配状态，由现有404或兼容重定向处理。

## 13. 数据与安全边界

本改版不新增API或数据库。

浏览器只允许保存：

- 二级栏`expanded`或`collapsed`。
- 每个大类最近访问的规范相对小类路由。

保存键必须包含成员ID，不能跨成员共享。

禁止保存：

- 邀请码。
- Session或Token。
- API Key。
- Prompt或正文。
- 工作区私有数据。
- 外部URL。
- 未校验`returnTo`。

## 14. 测试策略

### 14.1 单元与组件测试

- 16个页面到5个大类的映射。
- Admin 16、Editor 13、Viewer 9可见性。
- Viewer不显示管理大类。
- 大类没有可见小类时整体隐藏。
- 当前URL推导大类与小类。
- 默认小类跳转。
- 最近访问小类恢复。
- 角色变化后忽略无权限历史记录。
- 二级栏收起偏好按成员隔离。
- 加载时不泄露Admin入口。
- 面包屑大类层级。

### 14.2 路由与集成测试

- 16个规范路由保持不变。
- 旧深链接进入正确大类。
- Scope与`returnTo`行为无回归。
- 跨工作区和权限直接访问仍由服务端拒绝。
- 一级大类切换不产生404。
- 二级栏收起不改变当前页面。

### 14.3 移动端测试

- 390px第一步只显示大类。
- 选择大类进入小类列表。
- 返回全部分类。
- 深链接默认进入当前小类列表。
- Escape、焦点锁定、背景不可交互和导航后关闭。

### 14.4 E2E与视觉回归

- Admin、Editor、Viewer导航矩阵。
- 五个大类分别进入默认页。
- 从各大类切换后恢复最近小类。
- 完整运营闭环仍通过可见导航完成。
- 桌面双层展开、二级栏收起、手机两步抽屉建立稳定截图。
- 逐张检查文字截断、层级高亮、内容宽度和移动端溢出。

## 15. 验收标准

1. 桌面默认只同时显示5个大类和当前大类小类。
2. 其他大类的小类不会同时出现。
3. Admin仍能进入16个模块，Editor进入13个，Viewer进入9个。
4. Viewer不显示管理大类。
5. 所有规范路由和API合同保持不变。
6. 当前大类与小类在刷新、深链接、前进和后退后正确高亮。
7. 一级大类切换最多一次后进入具体页面。
8. 用户可以收起二级栏，主内容不丢失。
9. 390px使用两步抽屉，不并排挤压。
10. 独立非开发者能够解释“大类”和“当前功能”的区别。
11. Task 9B重新执行并记录真实反馈。

## 16. 实施顺序

1. 重构导航数据结构，增加大类ID、默认路由和小类归属。
2. 更新桌面一级栏和二级栏。
3. 迁移折叠偏好与最近访问行为。
4. 更新移动端两步抽屉。
5. 更新面包屑和路由高亮。
6. 更新角色、路由、移动端和视觉回归测试。
7. 重新准备并执行Task 9B。

## 17. 已知边界

1. 本次不解决页面内部信息密度问题。
2. 本次不新增每个大类的独立首页。
3. 一级栏始终占用80px；对极窄桌面视口仍按移动端断点处理。
4. 最近访问小类是本地展示偏好，不是跨设备同步业务数据。
5. Task 9B当前仍为`not_run: independent_non_developer_session_pending`，导航改版后必须使用新版环境重新测试。
