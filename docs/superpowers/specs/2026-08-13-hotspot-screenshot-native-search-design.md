# 热点榜截图与模型原生联网设计规格

## 目标

运营人员主动使用现有浏览器扩展截取公开热点榜页面，系统识别榜单条目并要求人工确认；确认后的热点才能交给运营智能体。智能体仅使用当前工作区文字模型厂商提供的原生联网工具补充资料，再结合目标账号的事实、风格与爆款资产生成候选内容，并继续经过现有事实和 RiskRAG 门禁。

本功能不抓取平台后台、不定时爬取热点、不接入 Tavily、Brave、Exa、SearXNG、RSS 或其他独立搜索服务。

## 核心流程

1. 用户从扩展明确选择“采集热点榜”，对当前公开页面执行可见区域或整页截图。
2. 截图进入工作区隔离的暂存任务，不直接写入内容库。
3. 现有视觉/OCR 适配器提取榜单名称、条目标题、原始排名和原始热度文字。
4. Web 页面展示截图来源、采集时间、OCR 状态和结构化条目。Admin/Editor 必须逐项确认、修改或排除。
5. 确认结果保存为不可变热点快照；原始 OCR 结果不能冒充已确认数据。
6. 用户为一个已确认条目选择目标平台账号并发起“联网研究”。
7. 服务端检查当前文字模型是否已通过原生联网能力检测。未通过则明确停止，不静默使用模型记忆或其他搜索服务。
8. 模型原生搜索返回的来源经过 HTTPS、URL、数量和字段校验，保存标题、URL、来源站点、访问时间和短摘录；无可验证 URL 时研究失败。
9. 运营智能体读取热点、来源、账号风格、已确认事实和爆款结构，生成选题、标题与文案候选。
10. 产物进入现有事实校验和 RiskRAG；证据不足、事实冲突或高风险时不能显示为可发布。

## 模型原生联网合同

联网是文字配置的“原生工具能力”，不是新的业务生成能力，也不加入现有 `Capability` 枚举。每个模型配置记录以下安全状态：

- `unknown`：未检测；
- `supported`：检测请求出现真实服务端搜索调用，并返回至少一个通过校验的 HTTPS 来源；
- `unsupported`：厂商或模型明确拒绝原生搜索工具；
- `failed`：鉴权、限流、超时或响应异常，不能据此判定永久不支持。

状态必须绑定模型配置版本、检测合同和检测时间。修改 Key、模型、地域、工作空间 ID 或端点后自动回到 `unknown`。

第一版只实现千问原生联网。千问使用官方 Responses API 的 `web_search` 和 `web_extractor` 工具；当前固定 `qwen3.5-plus-2026-04-20` 保持 experimental，真实能力只有经过管理员明确触发的小额检测后才标记 supported。通用 OpenAI-compatible 配置第一版返回 `unsupported/not_adapted`，不能把未知参数发给任意端点。

## 数据边界

- 热点截图是用户主动提供的时间点证据，不等于平台官方实时热度接口。
- 必须保存来源页面主机、页面标题、采集时间和截图完整/部分状态。
- 不保存 Cookie、Authorization、邀请码、模型 Key、页面表单内容或浏览器历史。
- 普通日志不得包含截图、OCR 原文、搜索词、搜索结果正文、生成正文或供应商错误正文。
- 搜索来源只能来自当前模型调用结果；模型生成但未出现在工具来源中的 URL 一律拒绝。
- 不允许跨工作区、跨账号或跨平台复用私有热点研究记录。

## 权限与失败处理

- Admin/Editor：采集、确认、研究、生成。
- Viewer：只读已确认热点和研究来源。
- 扩展令牌：仅能创建、上传和读取暂存任务，不能确认、研究或生成。
- Demo/Mock：只运行固定合成热点与 Mock 来源，不访问外网。
- OCR 失败仍保留暂存任务供人工查看，但不能自动确认。
- 原生搜索未支持、无来源、来源校验失败或供应商结果不确定时均 fail-closed。

## 第一版验收

- 任意公开页面只有在用户主动点击扩展后才能采集，不新增 `<all_urls>` 持久权限。
- 热点确认前不进入生成和智能体上下文。
- 千问原生搜索能力检测可区分 supported、unsupported、failed、unknown。
- 研究结果至少包含一个与厂商工具输出一致的 HTTPS 来源。
- 不支持原生联网的模型明确不可用，不调用独立搜索服务。
- 热点生成继续使用现有账号隔离、事实、风格、爆款和 RiskRAG 门禁。
