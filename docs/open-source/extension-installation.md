## 构建和加载

在仓库根目录执行：

```bash
pnpm --filter extension package
```

发布包生成在 `apps/extension/release/`。

Chrome：

1. 解压 Chrome ZIP。
2. 打开 `chrome://extensions`。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，选择解压目录。
5. 核对版本、权限和目标服务器后再操作。

Edge：

1. 解压 Edge ZIP。
2. 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 选择“加载解压缩的扩展”，选择解压目录。
5. Edge 尚未完成真实页面验证，不应据此声明兼容完成。

## 绑定服务器

- 本地开发允许 `http://localhost`、`http://127.0.0.1` 和 IPv6 loopback。
- 远程服务器必须使用 HTTPS，不允许 URL 凭据、fragment 或混淆主机名。
- 邀请码只用于一次短期令牌交换，提交后从输入和内存清除。
- 短期令牌仅存入 `chrome.storage.session`，不写入 URL、DOM、localStorage 或长期扩展存储。

## 安全模式

1. 用户主动打开受支持页面并点击采集。
2. 扩展验证 URL、平台、页面版本、锚点和 signature。
3. 扩展高亮预计采集区域并提示敏感区域。
4. 用户可以取消、重拍、裁剪并添加矩形遮挡。
5. 用户查看最终预览后确认上传。
6. 截图进入暂存区，Mock 或已配置的 OCR/视觉处理产生候选结果。
7. 用户必须在 Web 页面修正并确认，扩展不能直接写正式快照。

## 可选一键模式

一键模式默认关闭。只有同一服务器、平台、页面 signature、页面版本、扩展版本、采集区域和敏感区域已经完成一次安全模式后，用户才能主动开启。一键模式可省略重复选区和上传前预览，但不能跳过登录、验证码、平台限制或 Web 数据确认。

在 Popup 的“一键模式信任状态”中可以查看信任服务器、平台、页面版本和信任时间，并随时关闭。页面结构、敏感区域、服务器或版本变化会清除信任并退回安全模式。

## 解绑和清除数据

- 点击 Popup 中的“解绑”会撤销当前短期令牌，并清除 session 绑定和一键信任元数据。
- 点击“关闭一键模式”只清除一键信任元数据。
- 在浏览器扩展管理页移除扩展可清除该扩展的本地存储。
- 暂存任务和截图需通过 Web 管理流程取消或确认；取消和确认会执行幂等清理。

## 页面失配与常见错误

- `unsupported`、锚点缺失、未知版本或 signature 变化：停止采集，等待适配器更新。
- 敏感区域新增或扩大：重新进入安全模式并预览遮挡。
- 验证码或登录异常：用户自行在平台完成操作；扩展不会绕过。
- 令牌过期或撤销：重新绑定，不要在 URL 或日志中传递令牌。
- 上传失败：按有限次数重试；仍失败时保留可操作错误并退回安全模式。
- 无法打开 Web review：核对服务器 HTTPS、扩展绑定状态和工作区权限。

真实页面验证必须使用获得授权的账号，由用户自行登录并主动执行；请使用[真实页面人工验证模板](extension-real-page-validation-template.md)，不要向 Git 提交截图、账号名或私有业务数据。
