# 浏览器采集助手：安装与使用

当前扩展版本为 `0.3.0`。它帮助运营人员从抖音或小红书创作者后台采集可见区、选区或有边界的整页截图，识别结果仍需回到运营工作台确认。

## 安装 Chrome 版本

1. 解压 `operations-capture-extension-chrome-0.3.0.zip`。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录。
4. 核对名称为“运营数据采集助手”、版本为 `0.3.0`。

Edge 使用对应 ZIP，在 `edge://extensions` 加载。Edge 和 Windows 尚未完成运行验收，不能据此声明兼容。

## 连接运营工作台

本地便携版 API 地址固定填写 `http://127.0.0.1:51201`。扩展配对不再使用成员邀请码，也不会创建新成员：

1. 在运营工作台右上角点“连接扩展”，或进入“数据导入 → 浏览器采集”。
2. 点击“生成配对码”。配对码只能使用一次，5 分钟后自动失效。
3. 打开扩展，填写服务器地址和配对码，点击连接。
4. 核对扩展显示的团队、成员和服务器。

连接成功后，设备会保持连接，直到你或管理员解除。扩展内部使用的短期访问凭据每 8 小时自动续期，凭据不会显示、复制到 URL 或写入日志。Service Worker 重启或短期访问凭据到期时，会使用持久设备密钥自动续期，不需要重新配对。只有解绑、管理员撤销、成员被移除、工作区被删除、浏览器数据被清除、设备密钥丢失或安全清除等情况才需要重新配对。远程服务器必须使用 HTTPS；仅本机允许 `localhost`、`127.0.0.1` 和 IPv6 loopback 的 HTTP。

管理员可在“设置 → 成员与设备”查看已连接设备，并在确认后撤销某台设备。编辑者和查看者只能阅读连接说明，不能查看或撤销设备。

## 安全采集流程

1. 登录创作者后台并打开受支持的作品管理页。
2. 点击扩展中的“自动采集整页”。可见区和选区位于“更多采集方式”。
3. 整页采集的默认快捷键：macOS 为 `Command + Shift + 8`，Windows 为 `Ctrl + Shift + 8`。这只是默认值；浏览器可能因用户自定义或快捷键冲突而取消或更改分配，请以扩展弹窗显示的实际结果为准，并在浏览器的扩展快捷键设置中调整。
4. 整页自动采集最多滚动 30 屏、最多运行 20 秒。到达任一边界或页面变化时，结果可能标为 `partial`（部分采集）；请检查预览，必要时分段重新采集。
5. 检查扩展标出的采集区域；页面不匹配时扩展会停止，不会猜测。
6. 裁剪需要的区域。矩形遮挡默认关闭，只有确认需要时才主动开启并遮挡头像、昵称、手机号等敏感内容。
7. 检查最终预览后上传；预览不符合预期时取消，不要上传。
8. 等待 Mock 或已配置的 OCR/视觉服务生成候选数据。
9. 打开工作台的导入审核页，选择正确账号、修正数据并人工确认。

扩展只能创建和读取暂存任务，不能直接写入正式数据。取消或确认后，暂存截图会按既有生命周期幂等清理。

## 一键模式

一键模式默认关闭。只有同一服务器、平台、页面版本、页面签名、采集区域和敏感区域已完成一次安全采集后，用户才能主动开启。页面结构或敏感区域变化会自动退回安全模式；它不会跳过登录、验证码、平台限制或 Web 人工确认。

## 解绑与卸载

- 在扩展里点“解绑”：联网时会撤销服务端设备及其全部短期会话，然后清除本地设备身份、会话绑定和一键信任。离线解绑会先清除本地身份；工作台可能暂时仍显示设备，需要恢复网络后由管理员撤销。
- 点“关闭一键模式”：只清除非敏感的一键信任设置。
- 在浏览器扩展管理页移除扩展：清除扩展本地存储，不会删除工作台中的正式数据。
- 未确认的暂存任务可在工作台取消。

## 常见问题

- 配对码无效或已使用：回到工作台重新生成，不要继续尝试旧码。
- 连接无法恢复：浏览器数据或设备密钥可能已丢失。重新配对；不要把配对码或令牌放进 URL、截图或日志。
- 页面不支持、锚点缺失或页面签名变化：停止采集，等待适配器更新。
- 自动整页显示 `partial`：这表示达到 30 屏或 20 秒边界，或页面发生变化；检查预览后按需要分段重采。
- 敏感区域发生变化：重新预览并遮挡。
- 上传失败：检查工作台是否运行、服务器地址是否正确；有限重试仍失败时重新采集。
- 看不到审核页：确认当前成员仍有编辑权限，并从“数据导入 → 浏览器采集”进入。

真实平台验证必须使用获得授权的账号并由用户主动操作。请使用[真实页面人工验证模板](extension-real-page-validation-template.md)，不要提交账号名、截图、Cookie、配对码或业务数据。
