# 风控知识治理

公共知识只可收录人工合成、明确授权或允许引用的有限摘要及其来源元数据；工作区私有知识与公共知识严格分离，且抖音与小红书严格隔离。不得将版权不明的平台规则全文、第三方文章全文或真实用户资料打包进仓库。

来源等级：S1 平台官方规则/公告，S2 法律法规及监管材料，S3 团队真实违规记录（默认私有），S4 经审核行业案例，S5 未验证经验（仅低置信度提示）。文档经历草稿、已解析、待审核、生效、已替代/已失效；只有当前平台的生效版本参与扫描，历史版本仅用于追溯。

每条结论应验证引用、版本与生效时间；无有效证据时降级为“未检索到有效规则”，不得编造。上传资料和网页内容都是不可信输入，不能覆盖系统指令；Prompt Injection 防护只降低该类风险，不能成为安全保证。Mock 评估集仅用于工程回归，不能宣传生产准确率。

**AI 风控仅用于辅助判断，不保证通过平台审核。**
