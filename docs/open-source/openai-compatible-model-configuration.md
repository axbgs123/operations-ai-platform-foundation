# 接入自有 OpenAI 兼容文本模型

工作区管理员可以在“工作区设置 → 模型配置”中切换到“OpenAI 兼容”，接入团队自己
购买或部署的文本模型。该入口只支持 OpenAI Chat Completions 与 Models 的基础合同，
不代表兼容官方 OpenAI 的全部能力，也不支持视觉、OCR、Embedding 或图片生成。

## 智谱 GLM-5.3-Flash 快捷入口

模型配置页提供“智谱 GLM-5.3-Flash”快捷入口。它仍复用本节描述的受控
OpenAI-compatible 文本合同，但由页面固定以下参数，管理员只需填写智谱开放平台
API Key：

- 服务地址：`https://open.bigmodel.cn/api/paas/v4`
- 模型名称：`glm-5.3-flash`
- 展示名称：`智谱 GLM-5.3-Flash`

该快捷入口面向智谱国内通用 API，不使用 Coding Plan 专用端点。当前仅开放文字生成、
运营分析和运营智能体对话；模型本身具备的多模态及其他工具能力，需要单独完成输入、
费用和结果合同验收后才能在平台中开放。连接测试只检查密钥、服务和模型列表，不代表
生成质量已经验收。

上游合同参考：
[GLM-5.3-Flash 官方发布说明](https://autoclaw.z.ai/blog/model/glm-5.3-flash/)、
[BigModel/Z.ai OpenAI 接口配置](https://zcode.z.ai/cn/docs/configuration)。

## 需要填写什么

- 配置名称：只用于团队成员识别这项配置。
- 服务地址：例如供应商给出的 `https://example.com/v1`。
- 模型名称：必须与该服务 `/models` 返回的模型 ID 完全一致。
- 模型服务密钥：只在保存时提交，保存后不会回显。

正式环境只接受公开 HTTPS 地址。开发环境可以显式使用 localhost；内网地址、云元数据
地址、带用户名密码的 URL、重定向和不安全路径会被拒绝。读取配置时仅向管理员展示
脱敏域名，不返回完整地址、密钥、密文或密钥片段。

## 测试连接

保存后点击“测试连接（不调用模型）”。系统只请求该地址的 `/models`，验证密钥、
网络和模型名称，不发送 Prompt、运营数据、图片或生成请求。连接成功不代表生成质量、
结构化输出质量、长期稳定性或平台审核结果已经通过验收。

## 用量与费用

平台仍会执行工作区级并发、每分钟调用、每日请求、输入和输出文字量限制。由于不同
供应商价格合同无法由本项目可靠获知，兼容模型的记录会明确标为“费用未知”，不会把
0 显示成真实费用，也不会用虚构价格执行人民币预算判断。费用由模型供应商直接结算，
管理员仍应在供应商后台设置独立预算和告警。

每一次 HTTP 尝试仍会单独记录安全用量事件；日志不包含服务地址、密钥、Prompt、输入、
输出或供应商错误正文。失败不会自动切换到 Mock 或千问，避免生成来源和计费失真。

## 开源部署边界

模型配置和密钥不进入 JSON/ZIP 工作区备份，也不应提交到 Git、Issue 或示例数据。
迁移到另一台电脑后需要管理员重新配置。社区兼容状态表示工程合同已接入，不代表项目
维护者为第三方供应商提供可用性、价格或内容安全保证。
