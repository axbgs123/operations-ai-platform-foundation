# 浏览器采集助手隐私说明

## 扩展读取什么

扩展只在用户主动操作后处理当前可见标签页。它不读取 Cookie、密码、浏览器历史、隐藏接口或不可见页面，也不绕过登录、验证码、平台风控或页面权限。

上传内容仅包括用户最终确认的截图、平台、页面版本、本地采集时间、必要页面标识和暂存任务上下文。截图先进入工作区隔离的暂存区，扩展不能直接写成正式数据。

## 配对与会话

配对码由已登录的当前成员在工作台生成，不是成员邀请码，不会创建或修改团队成员。配对码一次性使用，5 分钟后失效；服务端只保存其 HMAC 摘要，不保存明文。

配对成功后，设备会保持连接，直到用户或管理员解除。扩展内部短期访问凭据每 8 小时自动续期，只具备创建、上传和读取采集任务的权限。凭据只保存在 `chrome.storage.session`，不会写入 URL、网页 DOM、localStorage、同步存储、日志或备份；浏览器数据或设备密钥丢失后必须重新配对。

只有管理员可在工作台查看设备名称、浏览器、扩展版本和使用时间，并确认撤销设备。页面不显示设备公钥、JWK、指纹、令牌或其摘要；编辑者和查看者没有撤销入口。

## 识别与人工确认

OCR/视觉识别只产生候选平台、作品标识、指标、区域坐标、置信度和识别版本。普通 CI 与本地验收使用固定 Mock，不调用付费模型。部署方接入其他服务时，应另外披露处理方、地域和保留策略。

结果必须由有权限的成员在 Web 中修正并确认。自动整页采集最多滚动 30 屏、最多运行 20 秒；达到边界或页面变化时可能是 `partial`，必须在上传前检查预览。矩形遮挡默认关闭，只有用户主动开启才会应用。一键模式只减少重复选区和上传预览，不增加权限，也不跳过人工确认。

## 保留与清除

- 取消任务或确认完成会触发暂存截图的幂等清理。
- 失败任务可按部署方保留策略暂存用于受控重试，过期后由清理任务删除。
- 解绑会撤销当前扩展会话并清除会话绑定。
- 关闭一键模式会清除 `chrome.storage.local` 中的非敏感信任元数据。
- 卸载扩展会清除扩展本地存储，不会自动删除工作台正式数据。

## 兼容性边界

平台页面可能随时变化。本项目不保证页面永久兼容，也不保证识别结果或内容通过平台审核。真实平台页面、Windows 和 Edge 的兼容性限制以验证文档的环境矩阵为准；合成或隔离浏览器证据不等于真实平台兼容。
