# 运营数据采集扩展隐私说明

## 工作方式

扩展只在用户主动操作后工作，只捕获当前可见标签页。它不滚动拼接完整页面，不读取 Cookie、密码、浏览器历史、隐藏接口或不可见页面数据，也不尝试绕过登录、验证码、平台风控或页面权限。

## 绑定和令牌

用户选择处理服务器并提交邀请码。邀请码只用于交换短期、受限且可撤销的扩展令牌，提交后不会长期保存。令牌只存于 `chrome.storage.session`，不会写入 URL、页面 DOM、localStorage、sync storage 或日志。

## 上传数据

上传字段限于最终确认的截图、平台、页面版本、本地采集时间、必要页面标识、工作区和暂存任务上下文。服务器地址始终在 Popup 中可见。截图只进入暂存区，不会由扩展直接写成正式数据快照。

OCR/视觉识别产生候选平台、作品标识、指标、区域坐标、置信度和识别版本。普通 CI 和本地验收使用固定 Mock，不调用真实付费模型或外网。若部署方配置其他 OCR/视觉服务，应在其服务端隐私说明中单独披露处理方、地区和保留策略。

## 人工确认和一键模式

识别结果必须在 Web 中由有权限的用户人工修正和确认。一键模式只减少重复选区和上传预览，不跳过数据确认，也不增加扩展令牌权限。页面 signature、版本、敏感区域、登录状态或处理失败会自动清除信任并退回安全模式。

## 保留、删除和撤销

- 暂存截图按任务保留策略处理；取消任务和确认完成会执行幂等清理。
- 识别失败时可保留暂存对象用于受控重试，超过部署方保留期应由清理任务删除。
- 用户可以在 Popup 主动解绑并撤销令牌。
- 用户可以关闭一键模式，清除 `chrome.storage.local` 中的非敏感信任元数据。
- 用户可以在 Web 中取消暂存任务，或联系工作区管理员删除受其控制的数据。

## 兼容性边界

平台页面可能随时变化。本项目不保证页面永久兼容，也不保证采集或识别结果通过平台审核。目前注册表仅记录脱敏 Fixture 验证；真实页面、Windows 和 Edge 验证状态以 `apps/extension/supported-pages.json` 为准。
