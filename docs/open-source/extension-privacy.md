# 浏览器采集助手隐私说明

## 扩展读取什么

扩展只在用户主动操作后处理当前可见标签页。它不读取 Cookie、密码、浏览器历史、隐藏接口或不可见页面，也不绕过登录、验证码、平台风控或页面权限。

上传内容仅包括用户最终确认的截图、平台、页面版本、本地采集时间、必要页面标识和暂存任务上下文。截图先进入工作区隔离的暂存区，扩展不能直接写成正式数据。

## 配对与会话

配对码由已登录的当前成员在工作台生成，不是成员邀请码，不会创建或修改团队成员。配对码一次性使用，5 分钟后失效；服务端只保存其 HMAC 摘要，不保存明文。

配对成功后签发最长 8 小时、受限且可撤销的扩展会话，只具备创建、上传和读取采集任务的权限。会话只保存在 `chrome.storage.session`，不会写入 URL、网页 DOM、localStorage、同步存储、日志或备份。

## 识别与人工确认

OCR/视觉识别只产生候选平台、作品标识、指标、区域坐标、置信度和识别版本。普通 CI 与本地验收使用固定 Mock，不调用付费模型。部署方接入其他服务时，应另外披露处理方、地域和保留策略。

结果必须由有权限的成员在 Web 中修正并确认。一键模式只减少重复选区和上传预览，不增加权限，也不跳过人工确认。

## 保留与清除

- 取消任务或确认完成会触发暂存截图的幂等清理。
- 失败任务可按部署方保留策略暂存用于受控重试，过期后由清理任务删除。
- 解绑会撤销当前扩展会话并清除会话绑定。
- 关闭一键模式会清除 `chrome.storage.local` 中的非敏感信任元数据。
- 卸载扩展会清除扩展本地存储，不会自动删除工作台正式数据。

## 兼容性边界

平台页面可能随时变化。本项目不保证页面永久兼容，也不保证识别结果或内容通过平台审核。真实页面、Windows 和 Edge 的状态以验证文档为准。
