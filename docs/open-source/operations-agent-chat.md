# 运营智能体对话与原任务执行

工作区的“运营智能体”现在提供两个入口：

- **对话**：像常见 AI 聊天工具一样新建会话、切换历史、发送问题和归档会话。
- **任务与执行**：保留原有每日建议、手动生成计划、批准或拒绝、执行进度、人工确认和结果摘要。

两者不是两套智能体。对话负责理解用户想解决的问题；需要采取行动时，只能调用现有
计划服务生成一份待检查计划。切换到“任务与执行”后，用户仍需明确批准，系统才会按
固定工具目录执行。对话不能直接发布内容、支付、删除数据或绕过事实和风控门禁。

## 聊天记录

聊天记录保存在服务端数据库中，并按工作区和当前成员隔离。其他成员即使属于同一个
团队，也不能读取你的会话。刷新页面或正常重启服务后，会话、消息以及关联的计划 ID
保持不变。Viewer 可以阅读自己的已有记录，但不能发送、归档或触发计划。

输入上限为 4,000 字。发送支持页面按钮和 `Command/Ctrl + Enter`。为了控制数据发送
范围，每次只向模型提供最近 12 条、合计不超过 12,000 字的上下文。聊天正文不会进入
结构化日志或轻量备份。

## 模型和费用

Mock 模式使用固定回复，不访问外网，也不产生费用。配置真实千问或 OpenAI 兼容模型
后，对话内容会发送给管理员选择的模型服务，并可能由该供应商计费。失败不会自动切换
到另一个供应商；用户消息会保留，并显示不含供应商私密错误正文的安全提示。

## 当前限制

- 对话只负责问候、澄清、解释状态和创建受控计划，不是可任意安装工具的通用 Agent。
- 聊天历史目前不包含在 JSON/ZIP 工作区备份中，因此跨电脑恢复不会带回聊天正文。
- 真实模型质量、费用、限流与长期可用性取决于使用者自己的供应商，连接测试通过不等于效果验收通过。
