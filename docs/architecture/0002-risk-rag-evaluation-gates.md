# ADR 0002：RiskRAG 评估门槛与反馈治理

- 状态：Accepted
- 日期：2026-07-23
- 范围：RiskRAG 工程回归，不是产品质量声明

## 背景

RiskRAG 的规则、Prompt、模型、Embedding 或评估集变化都可能改变扫描结果。普通 CI 不能调用外网、计费模型或真实私有数据，因此需要一个稳定、可重复、分平台的工程回归门禁。

## 决策

CI 只加载 `apps/api/tests/fixtures/risk_eval/douyin/` 和 `xiaohongshu/` 中人工合成且授权用于测试的 Fixture，并使用固定 Contract Mock。抖音和小红书分别计算指标、分别通过门禁，不提供跨平台聚合指标。

每次结果记录规则、Prompt、模型/Mock、Embedding 和 Fixture 版本，以及平台、样本量和运行时间。初始门槛为：

| 指标 | 门槛 | 方向 |
| --- | ---: | --- |
| 高风险召回率 | 0.90 | 不低于 |
| 安全内容误报率 | 0.10 | 不高于 |
| 引用正确率 | 0.95 | 不低于 |
| 无依据结论比例 | 0.01 | 不高于 |
| 严重度判断正确率 | 0.90 | 不低于 |
| OCR 低置信度降级正确率 | 0.90 | 不低于 |
| 固定 Mock 一致性 | 1.00 | 等同于不低于 |

所有指标保存分子、分母和空值规则。分母为零，或低于配置的最小样本量时，状态为 `INSUFFICIENT_SAMPLE`，门禁失败，不得用零、满分或跨平台合并值替代。

## 门槛理由与当前限制

首批每个平台有 11 个合成样本，覆盖明确风险、安全、边界、联系方式变体、图片文字、OCR 低置信度、无证据、正确/错误引用、S5 单独证据和历史规则。门槛用于发现确定性规则、验证器和 Mock 合同的工程回归；高风险召回与引用正确采用较高下限，无依据结论采用接近零的上限，一致性要求固定输入完全可重复。

当前样本规模很小，且不代表真实流量分布。以上数字不能用于宣传“生产级准确率”，不能声称平台审核通过率，也不能承诺扫描结果保证通过平台审核。真实模型评估仅能在发布前受控任务中执行，必须使用经过授权的数据和模型配置，不进入普通 CI。

## 反馈治理

反馈在工作区内绑定具体 scan、finding、平台、规则版本和证据版本。admin/editor 可提交，只有 admin 可审核。未审核、拒绝或撤回反馈不会产生规则更新候选；审核通过后也只产生工作区私有、需人工实施的可审计候选，不能自动修改官方/公共规则、阈值、权重或评估结果。反馈正文始终是不可信数据，不进入生成 Prompt。
